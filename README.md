## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들어졌는지 확인합니다.

## 실행 방법

Node.js 22와 Python 3.12가 있어야 합니다. 아래 명령은 Windows PowerShell에서 씁니다.
**각 묶음은 프로젝트 맨 위 폴더(`expense-tracker`)에서 시작해, 적힌 순서대로 한 줄씩 입력합니다.** 묶음이 끝나면 맨 위 폴더로 돌아와 있습니다(서버 켜기는 서버를 끌 때까지 그 창을 씀).

**처음 한 번만 준비**

```
cd frontend
npm install
cd ..
python -m venv .venv
.venv\Scripts\python -m pip install -r backend\requirements.txt
```

**앱 쓰기 (화면과 서버를 함께 켜기)**

1. 화면 빌드 (처음 한 번, 그리고 화면 코드를 고친 뒤마다):
   ```
   cd frontend
   npm run build
   cd ..
   ```
2. 서버 켜기. 기록은 `data/expense.db`에 저장됩니다. 서버를 끄려면 그 창에서 `Ctrl+C`를 누릅니다.
   ```
   cd backend
   ..\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```
   - 직접 확인용 데이터베이스(`data/expense-check.db`)로 켜려면, 서버를 켜는 줄 앞에 이 줄을 먼저 입력합니다: `$env:EXPENSE_DB_PATH = "..\data\expense-check.db"`
   - 같은 창에서 다시 실제 기록으로 켜려면 이 줄을 먼저 입력합니다: `Remove-Item Env:EXPENSE_DB_PATH`
3. 크롬에서 `http://localhost:8000`을 엽니다. 화면과 API가 같은 주소에서 나옵니다.
   - 서버가 꺼져 있으면 사이트 자체가 열리지 않습니다. 이미 열어 둔 화면에서는 위쪽에 연결 실패 알림이 보입니다.
   - 기록은 서버를 껐다 켜거나 컴퓨터를 다시 켜도 `data/expense.db`에 그대로 있습니다.

**개발할 때 (화면을 고치며 바로 보기)**

1. 위 2번처럼 한 창에서 서버를 켭니다.
2. 다른 창을 열어 프로젝트 맨 위 폴더에서:
   ```
   cd frontend
   npm run dev
   ```
   크롬에서 `http://localhost:5173`을 엽니다. `/api` 요청은 개발 서버가 `127.0.0.1:8000`으로 넘겨줍니다. 끄려면 `Ctrl+C`.

**자동 테스트**

```
cd frontend
npm test
cd ..\backend
..\.venv\Scripts\python -m pytest
cd ..
```

- 서버 테스트는 테스트마다 임시 데이터베이스를 쓰므로 실제 기록에 영향을 주지 않습니다.
